# 选题与双轴结构库

## 一、选题诊断

从规范冲突、裁判分歧、学说争论、新法与旧法对应、制度运行或经验反差中定位问题。把“某制度研究”缩成“哪类主体在何种条件下适用何项规则，为什么”。问题可以是概念或理论，不强求每篇都有真实案件。

检查：有法律相关性、有可争辩的回答、材料能取得、篇幅可承担、对既有理解存在可描述的增量。增量可为边界、反例、解释修正、材料发现或操作标准，不必冒称首创理论。以已检索范围为界报告，未检索到不等于无人研究。近年文献与经典原著结合，不统一限定近五年或引用数量。

## 二、轴 A：论文在贡献什么（S03 六种骨架）

| 结构类型 | 适用问题 | 论证最小骨架 | 关键验收 |
|---|---|---|---|
| 概念澄清 | 两个概念混同、内外延不清 | 分歧→规范/理论渊源→检讨→界定→边界检验 | 新定义有区分能力；不靠换名制造创新 |
| 理论重构 | 旧理论不能解释关键现象 | 准确重建旧说→失败前提→新命题→证成→最强异议→制度含义 | 新框架理由充分，而非只批判前人 |
| 类型归纳 | 案例规则繁多、差异不明 | 对象边界→分类维度及理由→逐类分析→共性差异→疑难适用 | 分类维度统一；重叠说明，不假装天然穷尽 |
| 制度演化 | 制度变化为何发生 | 起点→阶段证据→驱动力→因果/解释限度→规范评价 | 不写编年史；不以先后发生冒充因果 |
| 判例线索 | 个案揭示规则张力 | 案情争点→裁判理由→学说冲突→一般规则→类案与例外 | 区分法院意见与作者建议，个案不自动代表普遍实践 |
| 技艺升级 | 方法如何可操作地适用 | 使用分歧→前提诊断→正确理解→操作顺位/因素→案例检验 | 要件、因素与程序区分；步骤有根据 |

选择一个主导类型，可嵌入另一类型。例如先概念澄清再规则具体化。解释为什么这样组合，不机械叠加六套章节。原库举出的作者、论文和观点是写法线索，未经当前核验不能作为论文引文。原完整模板与可浏览 HTML：`source-library/S03/ORIGINAL_SKILL.md`、`source-library/S03/legal_paper_template_library.html`。

## 三、轴 B：以什么方法证明（与六种贡献结构不是同一分类）

| 研究方式 | 主要结构控制 |
|---|---|
| 法教义/规范解释 | 争议解释→规范位置与方法→要件/权利义务→法律效果→限度 |
| 案例研究 | 选案→相关事实与程序→裁判理由→作者评议→规则及适用边界 |
| 实证法学 | 问题→抽样/编码/设计→发现→解释→规范回应及限度 |
| 比较法 | 本国问题→功能等值对象→差异及原因→本土适用条件 |
| 制度建构 | 功能与评价基准→运行缺口→权限/规则→替代方案与成本→法律效果 |
| 法哲学/批判理论 | 既有命题与前提→反驳→替代解释→正当性→边界 |

立法评述、历史、书评、学说评议可按问题组合；书评先忠实重建对象再评议，参考书不能自动变成待评书目。没有必要把所有论文变成 IMRaD 或“现状—问题—原因—对策”。

## 四、章节蓝图

每节内部登记：子问题、接收的前提、核心判断、来源与理由、竞争解释、得到的结论、后文如何使用。并列章节可以共同支持主命题，不强求逐章前提依赖。标题只承诺实际证明的任务，不凭对称填章节。

题目—主问题—文献分歧—正文—结语逐项回查；课程短文按篇幅决定几节，没有统一“三至四节”限制。暂定字数预算只作篇幅管理，不将固定比例、引言长度或摘要长度写成 CSSCI/法学通用标准。

## 五、部门法分流

按规范对象选择检查重点：民法的请求、要件与效果；商法的主体/组织与交易责任；刑法的罪刑法定、构成与责任；程序法的权限、程序、证明与救济；宪法的权力/权利与解释边界；行政法的授权、裁量与审查；经济/竞争法的行为类型、效果与例外；国际法的渊源、管辖与适用；劳动社会环境法的保护对象、义务主体与执行。交叉领域先分清规则来源和程序层次，不硬归一门。
