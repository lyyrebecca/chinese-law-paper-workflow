# 论证与法学方法

## 从命题到理由

先判断正在提出哪类判断，再选证明方式。最小审查单元：主张、规范/理论/事实材料、从材料到判断的理由（warrant）、必要前提、竞争解释、结论范围。它们是思考工具，不是每段必须填的六个小标题。论证次序可先结论后证明，也可从疑难逐步推导。

| 命题类型 | 关键问题 |
|---|---|
| 现行法解释 | 对象规范是什么？有几种可成立解释？采用哪一种，文义、体系、目的、历史等为何支持？约束与例外是什么？ |
| 概念/理论 | 内外延是否稳定？必要与充分条件是否混用？前提是否成立？反例改变什么？ |
| 案例/群案归纳 | 为何选这些案？共同特征是否可比？反向案例如何处理？样本内描述为何能或不能外推？ |
| 制度评价 | 按何标准？该标准为何适用？价值冲突怎么取舍？ |
| 制度建议 | 为什么目标需要此手段？谁有权限？替代方法、成本、实施条件与副作用如何？ |
| 经验/因果 | 数据如何得到？设计能否识别因果？相关、机制与规范评价是否偷换？ |

作者原创推论可以靠理由成立，不要求每句都找现成文献“背书”；但推论依赖的外部事实和他人思想必须引注。解释方法不是永恒固定排序；刑法、宪法等特定语境的边界需单独核对。规范性问题先做足必要的规范论证，但不规定经验研究必须先“穷尽教义学”才可使用社科方法。

## 案例精读

相关事实→诉请/指控→程序→具体争点→适用规范→法院理由→裁判结论→作者评议。多数/少数意见、裁判理由/旁论、不同审级和判后学评分开。资料不足不补案情。说明个案如何使两种解释得到不同结果；若规则声称普遍适用，再检验类案、反例与例外。假设例必须标明，不冒充真实裁判，也不承担发生频率的证明。

## 分析框架压力检验

分类或审查步骤首先说明依据、任务与相互关系：并列、前置、权衡还是择一。不可将实体成立、程序可受理、证据门槛和救济效果塞在同一层。新分类最好覆盖研究对象并解释重叠；MECE 是设计启发，不是所有理论分类的数学证明。

选能拉开两种解释差异的材料演示判断，检查哪个前提受攻击后会让结论失败。准确重建最强对手再回应，回应可以反驳、接受、区分或缩窄本说；不凑反方数量、不制造稻草人。比较法与数字都不能自行推出中国法上的义务。

## 论证增量与章节衔接

比的是既有解释能解决什么、本稿多解决哪一步，而不是标题新、引用多、分类细就有创新。每节应说明完成的判断与全文关系；相邻章节已有理由可回指，不反复复述。核心段落不藏在脚注里，脚注放出处、必要补充与旁支争议。
