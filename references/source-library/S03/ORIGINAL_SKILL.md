# 法学论文模板库

## 使用说明

调用本 skill 时，按以下步骤操作：

1. **诊断阶段**：根据用户描述的研究问题，对照六类触发信号，判断论文类型
2. **确认阶段**：向用户说明判断结果和理由，征得确认（一篇论文可能跨两种类型）
3. **框架阶段**：按对应模板，为用户生成具体的论文骨架（含各节标题建议）
4. **论证阶段**：按模板的论证步骤，逐节协助用户填充内容

如用户研究问题跨越多种类型，说明各类型的侧重差异，让用户选择主导方向。

---

## 六种论文类型速查

| 类型 | 核心问题 | 代表学者 |
|------|---------|---------|
| 概念澄清型 | 这个概念到底是什么意思 | 张翔、陈端洪、强世功 |
| 理论重构型 | 现有理论框架根本错了 | 黄明涛、苏力 |
| 类型归纳型 | 这些案例/规则有什么规律 | 王贵松、应松年、陈光中 |
| 制度演化型 | 这个制度为什么这样变 | 强世功、苏力、陈光中 |
| 判例线索型 | 从这个案例能得出什么规则 | 苏力、李双元 |
| 技艺升级型 | 这种方法应该怎么更精确地用 | 张翔、黄明涛、高铭暄 |

## 类型一：概念澄清型

### 触发信号（满足其一即可）
- 学界对某核心概念存在多种相互矛盾的理解
- 实践中两个不同概念被混为一谈
- 某概念的内涵无法支撑当前的司法或立法操作
- 域外理论移植后发生了含义变形

### 论证模板

**第一步：呈现概念乱象**
列举学界或实务界对该概念的多种分歧理解，指出各种理解之间的相互扞格，以及由此造成的实践混乱。
> 关键句式："对X的界定，学界至少存在A、B、C三种立场……"

**第二步：溯源——概念从哪来**
追溯该概念的规范渊源（宪法文本、立法史、比较法），梳理其原始含义与演变脉络。这是后续"正本清源"的基础，也是批驳其他立场的武器。

**第三步：分析——现有界定错在哪（核心论证）**
逐一批驳既有立场，指出其内在矛盾、与规范文本的偏差、或无法解释特定案例。
> 注意：要说清"前人的逻辑在哪一步断裂"，而不只是"前人错了"。

**第四步：提出新的概念界定**
给出自己的定义，须包含三个维度：
- 内涵：是什么
- 外延：包括什么、不包括什么
- 功能：这样界定解决了什么问题

**第五步：验证——以案例或规范检验**
用新界定解释此前令人困惑的案例或规范现象，证明解释力。
> 关键句式："依据本文的界定，以下疑难得以解决……"

### 论文结构建议
```
一、问题的提出：X概念的理解困境
二、现有界定的检讨
   （一）A立场及其缺陷
   （二）B立场及其缺陷
   （三）C立场及其缺陷
三、X概念的规范渊源与本来含义
四、X概念的重新界定
   （一）内涵
   （二）外延
   （三）功能定位
五、新界定的适用：以若干疑难为例
六、结语
```

### 代表论文
- 张翔《基本权利的双重性质》：澄清"主观权利/客观秩序"并非对立而是基本权利功能两面
- 张翔《财产权的社会义务》：澄清社会义务是财产权内在构成要素而非外部限制
- 陈端洪《论宪法作为国家的根本法与高级法》：区分根本法的实质意义与形式意义
- 黄明涛《两种"宪法解释"的概念分野》：区分"宪法解释"与"合宪性解释"

### 常见失误
- 新界定太宽（失去辨别力）或太窄（解释力不足）
- 只批驳对手，但自己的新界定论证不足
- 忽略第五步验证，论文缺乏说服力收尾

## 类型二：理论重构型

### 触发信号（满足其一即可）
- 主流理论框架与现实明显脱节
- 各方批评热闹但无人提出系统性替代方案
- 移植的域外理论在本土"水土不服"
- 实践已走到理论前面，理论解释不了现实

### 论证模板

**第一步：确立"问题意识"**
描述现有理论框架的主要内容，然后指出其"解释危机"——哪些现象它解释不了，哪些推论它支撑不了。这是整篇论文的出发点，要写得让读者感受到理论重构的迫切性。

**第二步：诊断——既有理论的根源性缺陷**
不是枚举错误，而是找到那个"根本性的错误预设"。
> 例：苏力在《法条主义、民意与难办案件》中发现，法条主义预设了"法律与民意可以分离"这一根本性错误预设；黄明涛在《释法模式》中发现，批评者预设了"两种法律传统必然对立"这一错误前提。

**第三步：提出新框架的核心命题**
通常是1-2个核心论断，要足够清晰以至于可以被反驳。论文的所有论证都服务于这几个命题。命题要有反直觉性——如果人人都同意，就没有重构的必要。

**第四步：展开——分层论证新框架**
分2-4节从不同维度（规范、理论、比较法、历史）支撑核心命题。每节都是独立论证，共同服务于同一核心命题。

**第五步：回应可能的反驳**
主动预设最强的反对意见并回应。体现学术诚实，也是论文说服力的关键。
> 句式："或许有人会说……但这种反驳忽略了……"

**第六步：制度含义——新框架能改变什么**
说明新框架对司法实践、立法设计或学术研究的具体影响，避免论文停留在纯粹理论层面。

### 论文结构建议
```
一、问题的提出：现有框架的解释危机
二、既有理论的根源性缺陷
三、新框架的核心命题
四、论证一：[维度一，如规范分析]
五、论证二：[维度二，如比较法]
六、论证三：[维度三，如历史梳理]（可选）
七、对可能反驳的回应
八、制度含义与实践影响
九、结语
```

### 代表论文
- 苏力《法条主义、民意与难办案件》：重构"法律与社会"的关系框架
- 黄明涛《论全国人大常委会在与香港普通法传统互动中的释法模式》：颠覆大陆学界对庄丰源案规则的主流批评立场
- 苏力《法律与科技问题的法理学重构》：解构"法律万能论"，提出社科法学视角
- 强世功《中国宪法中的不成文宪法》：重构中国宪法研究的方法论基础

### 常见失误
- 批判既有理论写了3/4篇幅，自己的替代方案只有几段（建议批判:建构 = 4:6）
- 核心命题不够清晰，读者读完不知道作者主张什么
- 第六步缺失，论文停留在纯理论层面，无实践价值

## 类型三：类型归纳型

### 触发信号（满足其一即可）
- 该领域案例或规则繁杂，缺乏整体把握
- 实践中同类问题处理不一致
- 立法层面有原则但缺乏具体操作规则
- 需要为大量材料提供系统化分析框架

### 论证模板

**第一步：划定研究对象的边界**
界定"什么算作X"（宽泛定义 vs 狭窄定义），明确纳入研究范围的标准。
> 这一步往往被忽视，但决定了后续分类的合理性。

**第二步：提出分类标准（核心贡献）**
选择1-2个关键维度作为分类标准，解释为何这些维度最重要。维度的选择本身就是学术判断，要有说服力。
> 分类标准须满足MECE原则：相互排斥（Mutually Exclusive）、完全穷尽（Collectively Exhaustive）

**第三步：逐类描述与分析**
每一类都须包含：
- 定义特征（该类型有什么独特属性）
- 典型案例或规则（举例说明）
- 内在逻辑（为何此类案例有此特征）
- 与其他类型的边界（何种情形属于本类而非他类）

**第四步：跨类型比较与规律提炼**
分类完成后，指出各类型之间的共性规律和关键差异。这才是归纳的"升华"——不能只是分类，要有"分类之后的发现"。

**第五步：框架的应用——解决疑难**
用建立的分类框架处理若干疑难案例，证明框架的操作性。
> 句式："按本文框架，以下争议案例可以如此处理……"

### 论文结构建议
```
一、问题的提出：现有研究的碎片化困境
二、研究对象的界定与范围
三、分类标准的确立
四、类型A：[名称]
   （一）特征与界定
   （二）典型案例
   （三）处理规则
五、类型B：[名称]（同上）
六、类型C：[名称]（同上）
七、各类型的比较与规律总结
八、框架应用：疑难情形的处理
九、结语
```

### 代表论文
- 王贵松《行政法上不确定法律概念的具体化》：以"司法密度"为维度，归纳四类不确定概念及其审查强度
- 陈光中《认罪认罚从宽制度若干重要问题探讨》：按程序流程归纳制度各环节的规则
- 陈光中《刑事证据制度与认识论》：将证据认识论分为三种立场，逐一分析后提出新框架
- 应松年《政府信息公开法律制度研究》：按"主体—客体—程序—救济"四维度归纳制度要素

### 常见失误
- 分类标准不统一（A类按功能分，B类按主体分，C类按后果分）
- 类别过少（说明没有细分）或过多（说明标准有问题），以3-5类为宜
- 只分类，不提炼规律，论文缺乏理论贡献

## 类型四：制度演化型

### 触发信号（满足其一即可）
- 重大立法改革刚刚发生，需要理论化
- 司法实践与制度文本出现明显偏差
- 制度演变背后的逻辑尚未被学界识别
- 学界对改革方向存在争议

### 论证模板

**第一步：描述制度现状与变迁起点**
说明"制度从哪里出发"——既有制度的核心特征、运作逻辑与存在的问题。这是变迁叙事的"原点"。

**第二步：分析变迁的驱动力**
变迁不是偶然的。要识别驱动变迁的力量：社会压力、政治决断、司法推动、比较法借鉴，还是理论批判？这一步决定论文的解释深度。
> 只有找到驱动力，才能判断变迁方向是否正确，也才能预测未来走向。

**第三步：梳理变迁的阶段与路径**
将演化历程分为若干阶段，描述每阶段的标志性事件和制度特征。
> 注意：不是"编年史"，而是要揭示阶段之间的内在逻辑关联——为何从阶段A演化到阶段B？

**第四步：评价——变迁得失与未竟之处**
对已经发生的变迁作出规范性评价：哪些方向是对的，哪些问题尚未解决，哪些改革走偏了。从历史叙述转向规范判断。

**第五步：展望——制度的应然方向**
提出制度完善的具体建议，建议须有可操作性，不能停留在"应当加强""需要完善"等空话层面。

### 论文结构建议
```
一、问题的提出：制度变迁与理论滞后
二、制度变迁的起点：原有制度的特征与困境
三、变迁的驱动力分析
四、变迁的阶段梳理
   （一）第一阶段：[标志事件与特征]
   （二）第二阶段：[标志事件与特征]
   （三）第三阶段：[标志事件与特征]
五、对变迁过程的规范评价
   （一）积极面
   （二）未竟之处
六、制度完善的方向与具体建议
七、结语
```

### 代表论文
- 陈光中《我国监察体制改革若干问题思考》：分析从纪检到监委的演化动因，评价改革成就，指出刑事程序衔接问题
- 苏力《关于能动司法与大调解》：追踪能动司法的演化，既肯定现实合理性，又指出对司法独立的潜在威胁
- 陈光中《刑事和解初探》：梳理从地方实践到制度化的轨迹，提出立法建议
- 强世功《中国宪法中的不成文宪法》：追踪党的领导在历次宪法修改中的演化

### 常见失误
- 写成"制度介绍+问题清单"，缺乏真正的演化逻辑分析
- 历史叙述变成流水账，看不出各阶段之间的内在关联
- 第二步（驱动力分析）缺失，只说了"变成什么"而没解释"为何这样变"

## 类型五：判例线索型

### 触发信号（满足其一即可）
- 某个案例引发广泛争议或社会关注
- 司法判决与理论逻辑明显背离
- 案例中蕴含未被学界充分发掘的理论资源
- 需要从个案群中归纳出普遍适用的规则

### 论证模板

**第一步：选案与呈现案情**
选择具有代表性或争议性的案例，简洁呈现案情，聚焦与研究问题相关的法律争点。
> 不需要描述所有细节，只描述与论证相关的部分。

**第二步：点出"理论张力"**
说明这个案例为什么在理论上有趣——它与哪些既有规则或理论发生了冲突，或者它在哪个地方超出了现有框架的解释能力。
> 这一步决定论文的问题意识是否清晰。

**第三步：深入分析——案例背后的法理**
从多角度分析案例：
- 文义解释角度
- 目的解释角度
- 比较法角度
- 法理逻辑角度
每个角度都要清晰表达其对"如何裁判"的影响。

**第四步：从个案提炼一般规则（核心贡献）**
从具体案例归纳出可以适用于同类案件的一般规则或判断标准。
> 句式："一般而言，当……时，应当……"；"凡具备……要件的案件，应适用……规则"

**第五步：规则检验——适用于其他案例**
将提炼出的规则适用于其他类似案例，验证其普遍适用性，并指出例外情形与适用边界。

### 论文结构建议
```
一、问题的提出：[具体案例名]引发的理论困惑
二、案情概述与核心争点
三、理论张力：既有规则何以失效
四、多角度法理分析
   （一）文义分析
   （二）目的分析
   （三）比较法参照
五、一般规则的提炼
   （一）规则的核心内容
   （二）适用要件
   （三）例外情形
六、规则的检验：适用于其他类似案例
七、结语：对[相关制度/立法]的启示
```

### 代表论文
- 苏力《解释的难题》：以解释难题为线索，追问各种解释方法在疑难情形下的边界
- 李双元《论公序良俗原则的司法适用》：从大量案例中归纳公序良俗的类型化适用规则
- 高铭暄《宽严相济刑事政策与酌定量刑情节的适用》：从判例实践中提炼量刑情节的适用标准

### 常见失误
- "就案论案"——分析完这个案就结束了，没有提炼出一般规则
- 案例选择缺乏代表性，容易被质疑是"孤证"
- 提炼的规则过于宽泛，实际操作时无法指引具体判断

## 类型六：技艺升级型

### 触发信号（满足其一即可）
- 同一方法在不同案件中被以不同方式使用
- 法官或学者对某种方法的理解存在根本分歧
- 域外成熟方法移植后出现变形走样
- "原则"已确立，但"如何操作"仍不清楚

### 论证模板

**第一步：呈现操作层面的混乱**
通过案例或学术争论，展示该方法在实践中被以不一致的方式使用，说明混乱的后果（判决不可预期、论证不透明等）。

**第二步：诊断——混乱的方法论根源**
找出造成混乱的深层原因：
- 方法本身的模糊性？
- 使用者对其前提的误解？
- 方法被不当扩张适用？

**第三步：确立方法的正确理解**
回到方法的理论渊源和规范基础，澄清其正确含义、适用前提和边界条件。比较法资源在这里最有用。

**第四步：建立操作规则（核心贡献——精细化）**
提出更精细的适用步骤或判断标准。核心要求是"操作性"：读者读完后知道"在具体案件中，应该按什么顺序做什么判断"。
> 最好以判断树的形式表达：如果A则B，如果非A则C；当满足X时适用Y，当满足Z时适用W。

**第五步：以案例验证新操作规则**
将精细化的操作规则适用于此前的疑难案例，展示新规则的解释力和可操作性，同时指出其局限。

### 论文结构建议
```
一、问题的提出：[具体方法]适用中的混乱
二、混乱的表现及其后果
三、混乱的方法论根源
四、[具体方法]的正确理解
   （一）理论渊源与规范基础
   （二）适用前提与边界条件
五、精细化的操作规则
   （一）步骤一：[判断内容]
   （二）步骤二：[判断内容]
   （三）步骤三：[判断内容]
   （四）例外情形的处理
六、操作规则的验证：以若干疑难案例为例
七、结语：对[相关领域]方法论的影响
```

### 代表论文
- 黄明涛《两种"宪法解释"的概念分野与合宪性解释的可能性》：建立区分两种方法的可操作判断标准
- 张翔《基本权利的受益权功能与国家的给付义务》：建立给付义务的三步审查框架（有无义务→义务边界→审查密度）
- 张翔《我国国家权力配置原则的功能主义解释》：将"功能适当性"操作化为可适用的审查标准
- 高铭暄《预防性刑法观及其教义学思考》：建立区分正当预防与过度预防的操作标准

### 常见失误
- 停留在"应当重视X方法"的倡导层面，没有提出精细化操作规则
- 操作规则仍然是原则性表述，缺乏可判断的具体步骤
- 验证案例太少，无法证明规则的普遍适用性

## 跨类型组合说明

顶级论文往往是两种类型的嵌套：

| 组合方式 | 逻辑关系 | 典型示例 |
|---------|---------|---------|
| 概念澄清 → 理论重构 | 先清理地基，再建立新框架 | 张翔系列论文 |
| 类型归纳 → 技艺升级 | 先分类，再为每类提供操作规则 | 王贵松系列论文 |
| 制度演化 → 判例线索 | 以案例为制度演化的节点证据 | 陈光中系列论文 |
| 判例线索 → 理论重构 | 以案例为起点，向上推导理论困境 | 苏力系列论文 |

组合写作时，须在引言中明确说明两种视角的关系，避免论文结构显得散乱。

## 通用写作原则（适用于所有类型）

**引言的四要素**
1. 问题情境：为什么这个问题现在值得研究
2. 现有研究的不足：前人做了什么、留下了什么空白
3. 本文的核心论断：用一两句话说清楚本文主张什么
4. 论文结构：简述各节内容

**结语的两要素**
1. 核心结论的简明复述（不是内容摘要）
2. 未尽问题与后续研究方向

**论证的可检验性**
每个核心论断都应可以被反驳——如果一个命题无论如何都是对的，它就没有学术价值。写完每一节，问自己："如果有人要反驳我这一节，他会怎么说？"

**脚注的策略性使用**
- 正文：放主线论证
- 脚注：放对竞争性观点的回应、补充论据、方法论说明
- 不要把重要论证藏在脚注里
