# 第一批语料分析笔记（6篇）

## 一、张翔《基本权利的双重性质》（法学研究，2005）

### 用词特征
- 惯用"……的性质""……的内涵""……的功能"这类属概念词，而非"关于""有关"
- 大量使用"而非""并非""不过是"来辨析概念边界，语气坚定不拖沓
- 援引德文原文后立刻给出汉译，不用括号堆砌，而是用冒号或破折号自然过渡
- 多用"这一"而非"该"来指代前文，语感更自然
- "可以看出""我们可以理解"——以"我们"纳入读者，增加论证的共同体感
- 转折用"然而"多于"但是"，让步用"固然……但"
- 表强调：不用"非常""极其"，而用"极为""尤为""至为"

### 句式结构
- 段落首句往往是一个简洁的命题句（10字以内），然后展开论证
  - 例："在1958年的吕特判决中……"（先锚定案例，再分析）
- 频繁使用冒号引出列举，而非分段或加粗标题
- 长句惯用"……之下……"的介词框架，把条件/背景嵌入句中而非另起一句
- 例："在立法绝对主义之下，法院和法官不过是'法律的奴仆'"——背景嵌套在句首
- 引用判决原文后，用"接下来"或"进而"衔接，而不是"此外""同时"
- 多用动宾短语收尾，避免以名词短语结句（动词性结尾更有力）

### 论证逻辑
- 结构：起源（语词/规范/理论）→ 正面阐述 → 功能展开 → 相互关系辨析 → 反思/借鉴
- 借鉴部分不是生硬"他山之石"，而是先找到两者的相似处（"与德国魏玛宪法时代极为相似"），再具体对应
- 每个小论点先归纳，再举例，再收回来重申归纳——"总-分-总"在段落层面反复运用
- 批评某学说时，先承认其合理之处，再指出"真正需要我们反思的乃是……"

### 修辞与文风
- 几乎不用感叹号，情感藏在句式密度里
- 比喻少，但一旦用就很精准（"宪法上的基本权利条款几乎没有任何法律上的实效性"——"几乎没有"比"完全没有"更学术）
- 末尾收束时用"总而言之"而不是"综上所述"，语感更自然

## 二、苏力《法律与科技问题的法理学重构》（中国社会科学，1999）

### 用词特征
- 大量使用副词限定语："至少在相当大的程度上""在很大程度上""并不仅仅"——这是苏力风格的核心：拒绝绝对化
- 频繁使用"而不是""而非"作强对比，但后面往往不是简单否定，而是提供替代性表述
- "坦率地说"——苏力特有的口语化插入语，营造直接对话感
- 反问句用得精准："改革开放是当今的国策……但是它并不自然而然地成为一个法理学问题"——把意料之外的命题化成反直觉的推论
- 喜欢用"这并不是……而是……"的句型来澄清误解

### 句式结构
- 擅长用具体小例子（"奸宄杀人，历人宥"）打开一个大问题，再从这个例子回溯到理论
- 段落内部经常用"例如……又如……"结构堆叠多个案例，彼此佐证
- 喜欢预设读者的反驳然后回应："当然，人们会反驳说……我完全同意……但是……"
- 结尾段常做元反思：反省法学界本身的知识局限（"我们自己：法学界……是否会有意无意地……"）
- 长段落内用分号分隔并列分句，而不是断开成多段

### 论证逻辑
- 逻辑路径：先批评现有研究的框架缺陷（过于公式化）→ 重新界定问题域（总体的科技对总体的法律）→ 正面建构（因果关系论）→ 限制性条件（科学对法律的影响并非无限）→ 结语做价值平衡
- 善用"反例论证"：用荒谬的古代例子（惩罚动物、神判）来反向证明科学因果认识的重要性
- 结语不做简单"还需进一步研究"，而是提出具体警示（"法律中的科学技术的因素不是太多了，而是远远不够"）

### 修辞与文风
- 引用霍姆斯的名言作题记，但全文不作任何"名言崇拜"，而是批判性地使用
- 个人立场清晰但有节制——"在我看来""我觉得"出现，但不会不断重复
- 注释密度极高，但正文叙述不依赖注释，注释是补充而非支撑

## 三、陈端洪《法律程序价值观》（中外法学，1997）

### 用词特征
- 偏爱用"乃""即""亦"等文言助词，但并不生硬，与现代汉语句式自然融合
- "程序本位主义"vs"程序工具主义"——喜欢创造对称性的术语对
- "何以""在于""在乎"——古典问句词汇使文章有一种内在的追问感
- 用西文术语时通常先给中译，再在括号内附原文（而非反之），体现以中文为主的立场
- "可知""可见""足见"——归纳性词汇用得自然，不机械

### 句式结构
- 小节内部用数字列点，但列点内容本身仍是完整的论证段，而非要点词条
- 过渡句常用"以上从……两方面提出了……"来做小结，简洁不拖沓
- 援引西方案例（如Paul v. Davis）时，先给出结论性引语，再解释，避免大段铺垫
- 喜欢在段首直接给出判断（"是不是产生良好结果的法律程序就一定是可以接受的呢？答曰否"）

### 论证逻辑
- 三段式：程序工具主义（第一价值观）→ 程序本位价值论（第二价值观）→ 程序代价论（第三价值观/经济分析）→ 中国现状批判
- 批判中国现状时用三个标签（法律形式主义的虚无、职权工具主义、事实乌托邦），精炼且有可操作性
- 不追求"结论性强"的收尾，而是留有批判的余地："作为理论工作者，我们的使命是，透过制度的技术层面去从事'精神解剖'"

### 修辞与文风
- 偶用俗语（"赢了一场官司，输了半辈子"），但不显突兀，因为在讨论普通人的程序体验
- 批评意识形态时不直白攻击，而是用"在某种意义上""某种程度上"留有余地

## 四、强世功《中国宪法中的不成文宪法》（开放时代，2009）

### 用词特征
- 喜用"无疑""当然""毫无疑问"来推进论述，表面是确认，实则是在建立共识后进一步推进
- "不成文宪法"反复出现但不显重复，因为每次都在新的层次上使用
- 频繁使用"恰恰"——这是强世功文风的标志词，用于指出表面矛盾的深层吻合
- "看不见的宪法""活生生的宪法""真正的宪法"——引号的使用很密集，每个引号都在质疑既有概念

### 句式结构
- 喜欢在一大段论述后用一句话做"画龙点睛"的总结（通常以"可见"开头）
- 引用中西方思想家时用"如……所言"自然嵌入，不打断文脉
- 处理复杂的历史叙述时，用"其一……其二……其三"作显性结构，防止读者迷失
- 提问后立即自答，不悬置问题超过两句话

### 论证逻辑
- 从"背离主题"这一现象入手 → 历史解释（全球政治支配） → 方法论批判（三种流派的局限） → 构建替代框架（不成文宪法）→ 中国案例分析（四个渊源）→ 前瞻性结论
- 善于将政治学、历史学的发现转化为宪法学语言（如"三位一体"作为宪法惯例）
- 结论部分有意识地提出"真问题"，而不是总结已说过的内容

## 五、王贵松《行政法上不确定法律概念的具体化》（政治与法律，2016）

### 用词特征
- 概念词汇精确，几乎没有冗余限定词
- 惯用"所谓""此即""换言之"来释义，避免隐晦
- "无疑""当然"用于承认某种合理性，但紧接着转入"但是"
- 少用隐喻，以准确性为首要追求

### 句式结构
- 每节开头有一句功能性说明句（"在法学方法论的各种著作中……"），为下文铺垫
- 举案例时固定格式：先给案情梗概 → 引法院判词 → 评析判词的逻辑
- 注释中大量使用日文文献，但正文不对此作说明，维持论述的流畅性

### 论证逻辑
- 概念分析型论文的标准路径：概念起源 → 构造分析 → 类型化 → 具体化过程 → 司法审查标准
- 引入中国案例时，选择最有说服力的一个，而非堆砌案例

## 六、应松年《论行政强制执行》（中国法学，1998）

### 用词特征
- 行政法学教科书式的精准：每个术语第一次出现都有界定，界定后即全文使用
- "应该说""笔者认为""笔者所见"——第一人称用得自然，不回避立场
- 比较法部分用"简介""大致"保持客观距离，不夸大域外经验
- "亟待改进"——政策建议词汇，体现实践导向

### 句式结构
- 分类讨论时编号极其清晰：先总分类（间接强制/直接强制），再细分（代执行/执行罚）
- 引用他人定义后立刻用"可以发现"引出自己的评析，不拖延
- 政策建议部分语气转为陈述句+感叹号，增强紧迫感（相对罕见）

### 论证逻辑
- 实践导向型论文：定义 → 比较辨析 → 外国制度 → 中国制度 → 存在问题 → 类型分析
- 在指出实践中存在问题时，用"但是，由于……尚未……"句型，指问题而不指责人

## 跨文本共性提炼（初步）

### 用词共性
1. **拒绝绝对化**：多用"至少在一定程度上""往往""通常"而非"一定""必然"
2. **转折词偏好**："然而">"但是"；"固然"+"但"的让步结构
3. **推进词**："进而""由此""从而">"所以">"因此"（后者太教科书）
4. **归纳词**："可见""可以看出">"综上所述"
5. **强调词**："尤为""至为""极为">"非常""很"
6. **否定辨析**："并非""不过是""并不意味着"——学术否定通常是精确否定，而非全盘否定

### 句式共性
1. 段落首句简短有力（命题句），后文展开
2. 用冒号引出论据，而非另起段落
3. 让步结构："固然……但……"或"诚然……然而……"
4. 引用后立即评析，不堆积引文
5. 用"我们"而非"笔者"时，在建立共同体感；用"笔者"时，在表达个人判断

### 语气基调共性
1. 客观中有立场，立场不冒进
2. 批评有节制，先承认对方合理性
3. 不使用"显而易见""不言而喻"（这两个词常是AI的惯用词）
4. 结论有收敛性，不夸大研究意义

## 标志性的"非AI"表达举例

| 人类学者表达 | AI倾向表达 |
|---|---|
| "这与……何其相似" | "这与……非常相似" |
| "原因之一也许就是" | "主要原因是" |
| "坦率地说" | "客观而言" |
| "这是一个值得继续研究的课题" | "这需要进一步探讨" |
| "笔者认为……似别无良策" | "综合考量……最优方案是" |
| "颇为恰当地成为……的导论部分" | "已经成为……的重要组成部分" |
| "……何以……" | "……为什么……" |
| "……乃是……" | "……是……" |
| "基于对……的深刻反思" | "通过深入分析" |
